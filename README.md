# Динозаврики 🦕

Развивающая игра для детей 3–4 лет: 22 мини-игры с динозавриками — счёт до 10, все буквы,
логика и творчество. Все задания озвучены по-русски.

Играть: откройте сайт в Safari или Chrome и добавьте на главный экран
(Safari: «Поделиться» → «На экран „Домой“»), тогда игра откроется на весь экран, как приложение.

Чтобы Дина называла ребёнка по имени, добавьте к ссылке `?name=Маша&gen=Маши`
(второе — «для кого?»), для мальчика ещё `&g=m`.
